# 麦麦的单词花园

给麦麦和小屿的每周单词页：切换孩子后只显示对应词表；整周平铺、点击听英式发音、在原单词上显示彩色拼读分组。静态 HTML / CSS / JavaScript，可直接放在 GitHub Pages，无需账号、后端或构建。所有脚本随网站提供，不依赖外部 CDN。网站公开，发布的孩子姓名和词表任何访问者都可见。

## 本地运行

```bash
cd /workspace/maimai-words
python3 -m http.server 8000 --bind 127.0.0.1
```

通过 HTTP 服务运行，不直接双击 HTML（数据通过相对路径读取）。GitHub Pages 的 `/maimai-words/` 子路径也适用。

## 每周发布新词表

网站词表保存在 `data/weeks.json`，每周追加，保留所有旧词表和每行原始顺序。这次的 `单词.docx` 已录入，共 43 行、86 项；日期是本次录入日期，并非从文件推断出的教学周。

```bash
python3 scripts/add_week.py '/path/to/新一周单词.docx' \
  --title '第 2 周 · 新单词' --date 2026-10-26
```

小屿的词表加上 `--child xiaoyu`；麦麦可省略（默认 `maimai`）。

支持每行 1–3 组“英文｜中文”的普通 Word 表格，以及 Tab 分隔的段落；标题不作为单词读取，不支持合并单元格、嵌套表格或旧 `.doc`。脚本拒绝重复文件内容和重复编号，解析失败不修改现有数据。同一天有多份不同词表时可额外传 `--id`。

1. 核对表格顺序、中文和数量；不改原词表的拼写或顺序。
2. 为新词在 `data/phonics.json` 中补充、核对拼读提示。已知单词直接复用，新词不机械生成拼读。`blend` 表示字母组合，`syllables` 表示阅读节奏分组，`phrase` 表示短语。分组不都等同于单音素。原单词中的空格、大小写、括号和标点会保留；需要额外适配的词条可以用 `inlineParts` 指定与原词字母逐一对应的分组。可用 `say` 指定括号、省略号等词条的实际朗读文本。
3. 运行下方测试，本地核对页面，提交更新后按仓库已有方式发布 GitHub Pages。所有设备下次打开网址就能读取新目录和历史词表。

网站的“导入新词表”在当前浏览器内解析 DOCX，也能导入 JSON 备份，新增内容不覆盖旧词表；导入到当前选中的孩子名下。**网页导入仅保存在当前浏览器，不会修改 GitHub 或自动同步其他设备**；备份仅包含当前孩子的词表。清理浏览器或使用无痕模式可能丢失本地词表。旧版本的默写学习记录使用不同存储键，新版不会删除它们。

## 英音与拼读

朗读优先使用 Web Speech API 的 `en-GB` 设备语音。当前发布的单词同时带有同站点的英式合成音频；遇到不支持 Web Speech API 的内置浏览器时直接播放音频文件，不依赖系统语音包或第三方在线 API。每周新增词表后运行 `python3 scripts/build_audio.py`，需要安装 `espeak-ng` 和 `ffmpeg`，生成的 MP3 随网站发布。

本周所有 86 项都有人工编写的字母组合、音节或短语提示及英式音标。点击后直接在原单词上用不同颜色标出字母组合或节奏分组，不弹出拼读窗口。词典仍保留说明数据供后续校对，不使用中文谐音。较长单词的字母分组用于节奏提示，不代表严格的一块一个音素；不要用 TTS 去朗读单个字母块充当音素。未来导入的未知词仍可听整词，未核对的分组不着色。

## 检查

基础语法及数据检查无需安装依赖。浏览器回归检查需要 Python Playwright 与 Chromium（当前云环境已提供）：

```bash
node --check app.js
node --check docx.js
python3 -m unittest discover -s tests -v
```

测试会启动自己的临时 HTTP 服务与独立浏览器上下文，不触碰用户浏览器记录。语音测试使用可控的语音 API 替身验证英音选择、播放请求与错误处理；云端无声浏览器不能代替真实设备试听。

## GitHub Pages

站点入口为根目录 `index.html`，所有资源都使用相对路径。沿用仓库当前 Pages 发布方式即可，不需要构建。若使用“Deploy from a branch”，发布分支的目录选择 `/ (root)`。不要将任何 GitHub token 放入前端；浏览器上传不会直接写入仓库。

首次发布后，用手机和电脑核对：86 项顺序、点击播放与原词着色、切换历史词表、刷新后保留、Word 导入和备份恢复。
